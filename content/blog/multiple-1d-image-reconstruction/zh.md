Neural Field 让我很感兴趣的一点，是它把图像变成一个可以查询的函数：输入位置，输出颜色。加上 Fourier features 后，一个 MLP 就能把纹理和轮廓拟合得很清楚。我的硕士论文想沿着这条思路试另一种表示：不用网络权重，改用多个一维投影、插值和采样点。

这篇论文在 Boston University 完成，正式题目是 *Image Reconstruction Through Multiple 1D Approximations*，2025 年收入学校机构库。我先讲它的背景与网络对照，再讲一维方法怎样工作，以及采样、方向和预算上的实验。

## Neural Field：把图像和场景写成函数

一张图像通常存成像素数组。Neural Field 换了一个表示方式：训练一个多层感知机，也就是 MLP，输入坐标，输出这个位置的颜色。

$$
f_\theta(x,y)=(R,G,B).
$$

训练图像时，每个像素提供一对样本：位置和真实颜色。网络预测颜色，与原图比较，用误差更新权重；查询整张坐标网格，就得到重建图。它学的是这张图的函数表示，而不是物体类别。[Neural Fields 综述](https://arxiv.org/abs/2111.11426)讨论了这类坐标表示在图像、形状与场景中的应用。

### NeRF 为什么是一个好例子

NeRF 把这个想法带到了三维场景：给定位置和观察方向，预测密度与颜色。沿相机射线取样、合成像素，训练时让渲染图接近已知相机位置拍下的照片，训练后再从新视角查询同一个场景。[NeRF 论文](https://arxiv.org/abs/2003.08934)

![NeRF 官方乐高场景示意图](/images/multiple-1d/nerf-classic.webp)

*图源：[Mildenhall 等人的 NeRF 官方项目页](https://www.matthewtancik.com/nerf)，ECCV 2020。射线上的点交给场景网络，预测再沿射线组合；这是背景参考图，不是我的实验。*

这个组合有用，是因为新视角任务需要几何关系：不同照片里的像素来自同一个三维场景。共享密度场处理遮挡，颜色允许随观察方向变化，体渲染再把三维预测接回二维照片。它比逐张拟合图片多了跨视角的约束，也避免直接存一张很密的三维体素网格。这些是原始 NeRF 在当时新视角合成对照中有效的原因，不能推广成 Neural Field 在所有任务上都更强。[原论文的方法与比较](https://arxiv.org/html/2003.08934v2)

## Fourier features 放在 MLP 前面，细节为什么更清楚

只把 $(x,y)$ 喂给普通 MLP，往往先得到平滑的颜色块，细小纹理学得慢。这种偏向先拟合低频的现象叫频谱偏置。图像里的“高频”可以理解成颜色随位置快速变化，比如细线、纹理和锐利边缘，并不是图片分辨率本身。[Frequency Principle](https://arxiv.org/abs/1901.06523)

Fourier features 在坐标进入 MLP 之前，把它转换成多组正弦和余弦：

$$
\gamma(p)=\big[\sin(2\pi pB),\cos(2\pi pB)\big].
$$

这里 $p=(x,y)$，$B$ 的每一列指定一种频率和方向。MLP 得到的输入从两个坐标变成一组随位置变化的波形。下面是我 notebook 中的核心映射，$B$ 是固定的随机矩阵，不通过反向传播更新：

```python
phase = (2 * np.pi * coords) @ B
features = torch.cat([torch.sin(phase), torch.cos(phase)], dim=-1)
rgb = mlp(features)
```

训练目标仍是预测 RGB 与真实 RGB 的 MSE，改变的是输入表示。网络可以组合已有的快慢波形来拟合纹理，不必只从两个平滑坐标里逐步建立这些变化。NeRF 的位置编码与这种映射使用相近的正弦／余弦思路，但原始 NeRF 的频率设置和随机 Gaussian Fourier features 不完全相同。[Fourier features 项目说明](https://bmild.github.io/fourfeat/)

![Fourier features 原论文的输入映射和重建对照](/images/multiple-1d/fourier-features-reference.webp)

*图源：[Tancik 等人，NeurIPS 2020](https://bmild.github.io/fourfeat/)。上排不加映射，下排加入映射；看图像纹理和乐高的细小结构。各列是参考论文的不同任务，不是我的实验。*

这种改善也有尺度条件。频率过低，仍容易欠拟合；过高，可能把噪声和采样间隙里的不稳定变化也拟合进去。原论文用神经切线核解释映射如何调整有效带宽，因此它不是“频率越大越好”。连续可查询也不等于恢复了从未观测到的真实细节。[Fourier features 论文](https://arxiv.org/html/2006.10739v1)

我的图像对照里，约 66,800 的表示预算下，Fourier-feature 网络达到 **51.83 dB**，普通网络是 **27.08 dB**。这是后文模型比较表中的结果，不是 NeRF 的三维指标，也不能只按这两个数推断输入映射之外的训练条件完全相同。

![高预算下各模型的实际重建图](/images/multiple-1d/model-comparison.webp)

*我的论文图 5.19。上排从左到右是原图、Fourier-feature 网络、普通网络；下排是我的一维近似、Kernel Regression 和 LinearNDInterpolator。先看上排眼睛与毛发，再看下排与原图的区别。*

## 为什么继续试一维近似

坐标网络的效果很好，我想探索的另一部分是表示成本和预测来源：能不能保留“坐标到颜色”的接口，把里面的网络换成更容易检查的一维曲线？采样位置、曲线和组合权重都能直接看见，也方便研究有限预算应该花在哪里。

选择图像，是因为结果直观。哪里模糊、哪里出现条纹、点都选到哪里，一张图就能看出来。另一个方法上的参考是 AAA 有理逼近中的自适应选点：根据当前误差，逐步补充支撑点。我借用了这种选点思路，具体表示仍是投影和线性插值，并没有直接把 AAA 搬到二维图像上。

任务也需要说清楚：**这是对已知图像的表示与重建。** 选点时可以读取原图，拟合组合权重时也使用原图。它没有在这里解决“照片已经损坏，却不知道正确像素是什么”的复原问题，也不是训练一个模型去预测没见过的图片。

## 从像素到曲线，再从曲线回到图像

一条方向可以写成单位向量 $d_k=(\cos\theta_k,\sin\theta_k)$。像素位置 $p=(x,y)$ 在这个方向上的一维坐标是：

$$
s_k=x\cos\theta_k+y\sin\theta_k.
$$

例如，横向投影只保留横坐标。同一列里不同高度的点会落到相同位置，颜色信息就可能混在一起。换成斜方向，点的排列又会不同。多用几个方向，是为了缓解单个方向丢掉的位置信息。

![单方向投影的原图与重建结果](/images/multiple-1d/single-projection.webp)

*论文图 3.2。左边是原图，右边只用一个投影方向重建；条带说明单方向不能保留完整的二维结构，红点是采样点。*

完整流程可以分成四步：

1. **选点。** 保存若干像素的二维位置和 RGB 值。
2. **投影。** 每个方向分别计算一维坐标，按坐标排序；相同投影位置的颜色取平均。
3. **插值。** 对 R、G、B 分别建曲线，用相邻采样点之间的线性插值预测颜色。
4. **组合。** 把各方向的预测平均，或者用最小二乘拟合组合权重，得到二维重建结果。

用最小二乘时，$X$ 是各方向给出的预测，$y$ 是原图颜色，求的是：

$$
w^*=\arg\min_w\|Xw-y\|_2^2.
$$

下文三栏图里的 Average 和 Optimized，分别对应平均组合与拟合权重后的结果。这一步不能略掉：否则很容易把组合方式带来的改善，全部归给选点。

## 采样：先补当前最错的地方

随机采样实现简单，但不会区分一块平坦背景和一只猫的眼睛。点数有限时，花在两者上的预算是否一样值钱，是这组实验要回答的问题。

我的贪心方法先从一个点开始，用已有点重建，再找当前误差最大的点补进去。下面是说明逻辑的伪代码：

```python
samples = [random_pixel()]
while len(samples) < budget:
    curves = project_and_interpolate(samples, directions)
    reconstruction = combine(curves)
    error = pixel_error(original, reconstruction)
    samples.append(worst_unsampled_pixel(error))
```

实际计算也要控制开销。一张 256 × 256 的图有 65,536 个像素，逐点加入并反复评估会很重。论文采用了近似做法：每轮随机抽 5,000 个候选像素，从中挑误差最大的 10 个加入；同时避免保存所有中间重建图。这减少了每轮检查的范围，但它也不再是每一步都找到全图最差点的精确贪心。

![随机采样的重建与采样点分布](/images/multiple-1d/uniform.webp)

*论文图 5.2：随机采样，10,240 点、128 方向。左为平均组合，中间为最小二乘组合，右侧叠加误差图和红色采样点。*

![贪心采样的重建与采样点分布](/images/multiple-1d/greedy.webp)

*论文图 5.3：相同点数与方向数，改用误差驱动的选点。看中间重建的眼睛、耳朵和身体轮廓，再看右侧点集中在哪里。*

MSE 是重建颜色与原图颜色的平均平方误差；PSNR 把误差转换成对数尺度，数值越高表示像素误差越小。它们衡量的是像素接近程度，所以我也一起看主体细节、背景和颜色。

| 采样方式 | PSNR（dB，越高越好） | MSE（越低越好） |
| --- | ---: | ---: |
| 随机采样 | 19.96 | 0.010084 |
| 贪心误差选点 | 25.72 | 0.002680 |
| 贪心 + 空间分散 + 边缘先验 | 18.54 | 0.013996 |

*论文表 5.1，均为 10,240 点、128 方向。同一设置下，贪心选点比随机采样高 5.76 dB，MSE 约减少 73.4%。这是该图的对照结果，不是整个数据集的平均收益。*

### 为什么“多看边缘”反而差了

我给选点分数加了空间距离和图像梯度：远离已有点的候选得到加分，变化剧烈的边缘也得到加分。希望点分布更均匀，同时照顾主体轮廓。

![加入边缘与空间分散要求后的重建](/images/multiple-1d/edge-prior.webp)

*论文图 5.4。点沿轮廓集中，但中间的重建并没有因此变清楚；PSNR 降到 18.54 dB。*

这个结果提醒我，轮廓点多，不等于插值需要的信息足够。边缘两侧是什么颜色，同样决定了曲线该怎样变化。如果点都集中在边缘，却没有足够的周围信息，经过一维投影后可能仍然恢复不好。论文用这个解释讨论失败原因；它是对图像和点分布的判断，还不是把每个因素单独验证后的机制结论。

RGB 的误差计算也做了对照。三通道平均误差对应 24.50 dB，先平均通道再算误差为 25.00 dB，按最大通道误差选点为 25.72 dB。最后一种会优先处理某个颜色通道特别差的位置，避免严重的颜色偏移被另外两个通道平均掉。

## 插值方式会改变后面的选点

我还试了 spline。曲线更平滑，听起来应该更好，但同样 10,240 点、128 方向，线性插值为 **25.72 dB / 0.002680 MSE**，spline 为 **23.72 dB / 0.004248 MSE**。

这里有个容易漏掉的关系：插值不仅负责最后出图，也参与每轮误差计算。换一种插值，早期重建就会变化；误差最大的位置随之变化，后面选到的点也变了。论文还做了稀疏点下的图像比较，以及复用线性方法所选点的比较，来观察这两部分的影响。

所以这次试验中，“更平滑”没有自动变成“更准确”。线性插值虽然简单，却和当前选点方式配合得更好。我保留了线性方案。

## 有限预算，花在点数还是方向数上

方法有两个主要旋钮：采样点数 $N$ 和投影方向数 $K$。多一点，能保存更多原始颜色；多一个方向，则多一种理解这些点的位置关系的方式。

首先要区分两种存储方式：

| 表示方式 | 保存什么 | RGB 下的标量数量口径 |
| --- | --- | --- |
| 预计算一维曲线 | 每个方向的投影位置与颜色 | $4KN+2$ |
| 紧凑表示 | 原始二维位置与 RGB，使用时再建曲线 | $5N+2$ |

这是论文的近似表示预算，不是最终文件大小。第二种少存了每个方向的一套曲线，使用时就得再做投影、排序和插值。省存储与省计算在这里不是同一件事。

参数扫描使用了 128 × 128 的图像，并排除了预计算表示超过 300,000 标量的组合。在这些设置下，同预算增加点数通常比增加方向更直接地降低误差。但方向并非无用：它能减少单一方向留下的条纹与重影，也会影响贪心过程判断哪些点值得留下。

![四方向与六十四方向的图像重建对比](/images/multiple-1d/projection-count.webp)

*论文图 5.13，两边均用 8,800 个采样点，左边 4 方向，右边 64 方向。注意背景里的重影与条带；这是固定点数下的方向对照，不能当成预计算表示的同存储预算比较。*

### 选点多用方向，重建少用方向

由此我试了一个办法：在选点阶段用更多方向，把位置选得更好；最后只留少量方向做重建。重要的是，留下哪几个方向？

| 方向策略 | PSNR（dB） | MSE |
| --- | ---: | ---: |
| 选点与重建都用相同的 3 方向 | 22.22 | 0.005930 |
| 多方向选点，重新生成 3 方向重建 | 19.63 | 0.010886 |
| 多方向选点，保留原方向中的 3 个 | 26.78 | 0.002100 |

*论文表 5.5：20,001 个采样点，最终 3 方向，各方案五次试验的平均结果。*

![保留选点方向子集后的重建结果](/images/multiple-1d/direction-subset.webp)

*论文图 5.16，对应保留原方向子集的方案。表里的数值是五次平均；图上是一次结果，两者不必完全一样。*

重新生成方向，相当于让最后的重建器换了一套看点的方式。之前针对那组方向选好的点，未必还合适。保留子集更好地维持了选点与重建之间的联系。这个实验比“先复杂、后精简”更具体：精简时要保留哪些关系，会直接决定结果。

## 和神经网络比，结果怎样

最后，我用 256 × 256 图像比较普通网络、Fourier-feature 网络、Kernel Regression、LinearNDInterpolator 和我的方法。我的方法用 64 方向；对非参数方法，用大约 $5N$ 个标量代表采样点的存储预算，网络则按权重数量计数。因此它是近似表示规模的比较，不保证运行时间或实际字节数相同。

| 方法 | 约 4,400 预算 | 约 17,000 预算 | 约 66,800 预算 |
| --- | ---: | ---: | ---: |
| 神经网络 + Fourier features | 37.86 | 50.44 | 51.83 |
| 普通神经网络 | 23.14 | 26.69 | 27.08 |
| 多重一维近似 | 18.12 | 22.34 | 29.40 |
| Kernel Regression | 12.39 | 22.44 | 27.22 |
| LinearNDInterpolator | 15.79 | 22.60 | 27.46 |

*论文表 5.6–5.8，数值为 PSNR（dB）。网络实际权重数为 4,419 / 17,027 / 66,819；其余方法按 4,400 / 17,000 / 66,800 计。*

Fourier-feature 网络明显最好。我的方法在高预算时超过普通网络和两种传统对照，在低预算时落后于普通网络；中间预算还略低于两种传统方法。论文中有一句概括把优势写得太宽了，按表格看，更准确的结论是：**这是一种有具体取舍的图像表示，没有全面优于神经网络。**

我喜欢它能让人直接看到预算花在哪里：点会集中到高误差区域，眼睛和轮廓得到更多关注。但这也伴随代价，背景可能出现条纹，颜色不够均衡。更简单的一维组件也没有让整个选点过程自动变便宜；没有完整的耗时与内存对照，就不能从插值简单推导出整体更快。

做完这项研究，我留下的是一组可以解释的实验：哪些点值得存，哪些先验没有帮上忙，怎样精简方向，以及精简时为什么不能把选点与重建的关系拆散。这些问题比给方法贴上“轻量”标签更实在。
