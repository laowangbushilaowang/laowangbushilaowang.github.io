选本科论文题目时，我的想法很直接：想做神经网络。那时神经网络很火，图像又是一种容易展示结果的方式。一张有噪点、雨纹或模糊的照片放在左边，处理后的图放在右边，别人不用先听半小时介绍，就能看出这个模型在做什么。

所以我选择了图像复原，以 MPRNet 为基线，做了一个叫 EMRNet 的多阶段网络。工作集中在注意力、激活函数、归一化和阶段间的信息传递上，尝试去噪、去雨和去模糊。

这次论文，我现在不觉得特别成功。它更接近在一个已有模型上尝试改结构：注意力可以怎么调，激活函数能不能换，阶段之间能不能传递更有用的信息。我并没有充分地从某个明确问题的原理出发，再一步步论证为什么必须这样设计。下面把主要改动和它们的理由讲清楚，也讲这种做法欠缺了什么。

## 先理解基线：为什么分三阶段恢复

图像复原和目标检测的要求不太一样。检测器找到目标的位置和类别就完成了主要任务；复原网络要输出一整张图，纹理、颜色和边缘都在结果里。去掉雨纹时，不能顺便把头发、树枝和电线也抹掉。

[MPRNet](https://arxiv.org/abs/2102.02808) 把恢复分为三个阶段，前两个阶段使用编码器—解码器，第三阶段用原分辨率网络 ORSNet。我的改动保留了这套骨架。

![EMRNet 的三阶段网络结构](/images/emrnet/architecture.webp "从上到下依次是三个阶段。前两阶段提取多尺度特征，第三阶段使用 ORSNet；虚线表示跨阶段信息传递。右侧图像用于说明阶段输出，不是消融对照。")

读这张图，可以先看两条路线：横向是每个阶段怎样处理图像，纵向是前面算出的特征怎样继续往下传。

1. 第一阶段把输入分成四块，分别提取局部特征，再逐步合并。
2. 第二阶段处理两个更大的区域，用编码器—解码器扩大上下文范围，并接收前一阶段的特征。
3. 第三阶段在整张图的原分辨率上继续处理，生成最终结果。

“原分辨率”是指第三阶段主要处理分支不再反复缩小、放大特征图，不意味着所有输入特征都从未下采样。前两阶段的多尺度特征仍会对齐后传进来。

图里的几个缩写需要单独认一下：`ACAB` 是调整通道注意力后的特征块；`SCAM` 位于前两阶段输出与下一阶段之间；黄色 `C` 和 `Concat` 表示特征拼接，右下角的 `+` 表示残差相加。第三行绿色的 `ORB` 是原分辨率处理块，它们组成 ORSNet。SAB、激活函数和归一化属于模块内部的改动，这张总图没有逐层展开，不能仅凭它判断所有细节。

**图上保留的三阶段、编码器—解码器和 ORSNet 来自 MPRNet。** 我的主要工作是修改骨架里的块和阶段间连接，不是重新提出整套多阶段结构。

这个安排让我理解了多尺度和细节之间的取舍。缩小特征图，网络更容易把较大范围的信息放在一起判断；但细小纹理会受到影响。最后保留一条原分辨率分支，就是让前面得到的上下文有机会和局部细节一起发挥作用。

## 主要改了哪些地方，为什么这样改

在这套骨架上，我调整了通道注意力，称为 ACA；在解码器里加入空间注意力块 SAB，并对阶段间的监督信息传递做了 SCAM 的尝试。

把基线和我的改动放在一起，更容易看清这篇论文的工作范围：

| 位置 | MPRNet 基线 | 我的尝试与理由 |
| --- | --- | --- |
| 特征处理块 | CAB 已有通道注意力 | 调整为 ACA，让通道加权更适合恢复特征；图中以 ACAB 表示调整后的块 |
| 解码器 | 多尺度特征恢复与融合 | 加入 SAB，尝试按位置区分需要恢复的区域 |
| 阶段连接 | SAM 与跨阶段特征融合 | 尝试 SCAM，让传给下一阶段的特征有更明确的通道选择 |
| 非线性计算 | 基线主要特征块使用 PReLU | 在不同位置尝试 Mish、Swish，改变响应和梯度的形态 |
| U-Net 内部 | 核对的基线实现未使用 InstanceNorm | 加入 InstanceNorm，尝试调整特征统计、减少伪影；同时需要留意颜色和对比度 |

第三阶段的 ORSNet 是保留的基线设计，应和上面这些改动分开看。[MPRNet 原作者实现](https://github.com/swz30/MPRNet/blob/main/Denoising/MPRNet.py)

### ACA：已有通道注意力，为什么还要改

原模型已经会给通道加权，所以我的工作不是“第一次加上通道注意力”。ACA 的方向是调整这套选择机制，让与恢复有关的响应得到更合适的权重。

可以把特征想成一组对边缘、纹理、颜色等不同内容的响应。同样明显的响应，有的来自真实纹理，有的来自雨纹或噪声。通道加权希望保留有用信息、压低无关响应，但仅靠“响应强”并不能分清两者。这是改通道注意力的合理动机，也说明它并不自动解决退化识别的问题。

通道不是图像里红、绿、蓝三种颜色，而是卷积网络计算出的特征响应。常见通道注意力先汇总每个通道的信息，生成权重，再乘回特征图。理解它的运算关系，可以写成下面这个简化例子；这是原理示意，不是 ACA 的完整实现：

```python
summary = features.mean(dim=(2, 3), keepdim=True)
weights = channel_gate(summary).sigmoid()
output = features * weights
```

输入 `features` 是 `[B, C, H, W]`，汇总后是 `[B, C, 1, 1]`。每个通道获得一个权重，再广播到它的所有位置。空间注意力则生成随位置变化的权重，让同一张图里的不同区域受到不同处理。

### SAB：把位置选择放进解码器

SAB 放在解码器，是为了让多尺度信息重新汇合、恢复空间细节时，增加一次按位置加权的机会。雨纹有方向，模糊和噪声也可能在不同区域有不同强度；全图统一处理，未必能照顾这些差异。

但空间权重不是一张天然正确的“退化地图”。一条细线可能是雨，也可能是树枝。加入 SAB 提供了按位置选择的能力，是否真的更好地区分了雨纹和边缘，需要看对应区域的恢复结果和对照实验。这里能解释的是改法与动机，不能凭模块名称认定它成功解决了问题。

## SCAM：改的是阶段之间传什么

如果三个阶段只是把图片依次丢给下一个网络，前面提取出的中间特征就浪费了。MPRNet 还传递编码器和解码器的多尺度特征，这部分叫跨阶段特征融合（CSFF）。[基线实现](https://github.com/swz30/MPRNet/blob/main/Denoising/MPRNet.py)

另一条连接是监督注意力。基线的 SAM 会从当前特征生成阶段输出图，再由这张图生成注意力权重，调整传给下一阶段的特征。这里的“监督”来自阶段输出参与训练，不是人工逐像素画一张注意力图。

```text
当前阶段特征 ──→ 阶段输出图 ──→ 注意力权重
      │                              │
      └──────── 特征加权与残差 ───────┴──→ 下一阶段

编码器 / 解码器多尺度特征 ─────────────────→ 下一阶段
```

我做 SCAM 的出发点，是让阶段间传递的信息更有选择性：前一阶段得到的特征中，哪些值得继续增强，哪些不必全部带到下一阶段。图中的 SCAM 正好放在这样的交接位置。

基线 SAM 已经利用阶段输出引导特征传递；SCAM 进一步强调通道选择。上面的流程解释的是基线的机制，不能当成 SCAM 的完整公式。具体怎样产生通道权重、与监督信号怎样结合，才是判断这一改动是否成立的关键；只画一个新模块框，还没有回答这些问题。

这件事也提醒我，改模块要看它在整个网络里的位置。一个阶段单独输出看起来更好，未必意味着传出去的特征对下一阶段也更好；最终结果、阶段输出和中间连接需要一起看。跨阶段传递本来就是 MPRNet 的设计，我的工作是在这个基础上改，而不是从零提出多阶段复原。

## 激活函数和归一化：小改动也会改变图像

除了注意力，我还在不同位置尝试 Mish 和 Swish，在 U-Net 中加入 Instance Normalization。这些改动没有整体结构图那么醒目，却会影响每层怎样处理数值。

Swish 的形式是 $x\sigma(x)$，Mish 是 $x\tanh(\mathrm{softplus}(x))$。我尝试它们，是希望改变网络的非线性表达和梯度传播。需要注意，MPRNet 的主要特征块本来使用 PReLU，也会保留负响应，因此不能用“比 ReLU 平滑”就解释为什么一定优于基线。函数性质提供的是尝试理由，效果还得比较。

InstanceNorm 按每张图、每个通道分别计算均值和方差。它不依赖整个 batch 的统计，对小 batch 很方便。但图像复原要保留亮度和对比度，归一化恰好会改变这些统计信息。是否学习额外的缩放、偏移参数，以及放在哪一层，都有影响。[PyTorch 的定义](https://docs.pytorch.org/docs/stable/generated/torch.nn.InstanceNorm2d.html)

这和分类任务的直觉不完全一样。分类时，光照变化可能是需要忽略的干扰；复原时，输出颜色和输入场景对得上，本身就是任务的一部分。因此我不能只看图像干净了多少，也要看有没有色偏、细节变淡或过度平滑。

## 怎样判断恢复得好不好

去噪、去雨、去模糊都输出图像，但退化不一样。同一套结构可以用于这几类任务，不等于同一份权重无需训练就能处理所有退化。

| 任务 | 输入里的主要问题 | 看结果时容易漏掉什么 |
| --- | --- | --- |
| 去噪 | 随机扰动盖住细节 | 噪点少了，纹理也一起没了 |
| 去雨 | 雨纹与真实边缘混在一起 | 细线、树枝是否被误删 |
| 去模糊 | 边缘和纹理被摊开 | 看起来锐了，却有重影或伪影 |

数值评价里常用 PSNR 和 SSIM。PSNR 根据像素误差计算：

$$
\mathrm{PSNR}=10\log_{10}\left(\frac{\mathrm{MAX}^2}{\mathrm{MSE}}\right).
$$

`MAX` 是像素范围上限：归一化到 0—1 时取 1，8 位图像取 255。MSE 越小，PSNR 越高。SSIM 比较局部亮度、对比度和结构。两者可以帮助比较，但裁边、颜色空间和归一化方式要一致。

多项改动一起加入时，最终分数只能评价整个版本；要知道是哪一项有效，就得逐项消融，并保持数据划分和训练预算一致。参数更多、训练更久，也可能带来改善，不能把所有变化都归给新的模块。

## 为什么我不觉得这是一篇很成功的论文

回看这次工作，我更像是在问：“这个网络还能加什么、换什么？”注意力、激活函数和归一化都有现成的理论解释，把它们放进去，也能写出各自的设计动机。但这些理由还不够构成一个完整的研究问题。

比如，ACA 是为了让通道权重更合适。可基线到底在哪里选错了？它是把噪声放大了，还是把纹理压低了？如果这些现象没有先分析清楚，换一种通道加权方式，就仍然是在尝试模块。SAB 同样如此：能按位置加权，并不等于它学到的权重真的分清了雨纹和真实边缘。

SCAM 也不该只用“增强信息传递”解释。需要讲明白原来的传递缺了什么，新的通道选择改变了什么，以及阶段输出和最终恢复是否支持这个解释。否则，结构图上多了一个框，研究问题却没有变得更清楚。

我缺的是从具体失败现象到原理分析、再到有针对性的改法和验证这条联系。即使某个版本分数更好，也不等于已经解释了它为什么更好。这是我觉得论文不够成功的主要原因，而不只是改动数量不够多。

作为本科阶段的实践，它仍然让我真正接触了一个完整网络：读结构、改模块、理解张量和阶段连接。但我对这段经历的评价更接近一次模型改造练习。它让我开始区分：完成一个能工作的模型，与提出并回答一个研究问题，需要做的事情并不一样。
